## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/chetnalohani994-lang/agentic-drug-discovery.git
cd agentic-drug-discovery
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

### 3. Activate the virtual environment

For Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Configure environment variables

Create a `.env` file in the project root and add the required API configuration.

> **Note:** Never upload your `.env` file or API keys to GitHub.

### 6. Run the pipeline

```bash
python main.py
```

### 7. View results

Generated results are available in:

```text
results/final/
```

These include:

- Final candidate ranking
- Lead analysis
- Lead analysis report
- Docking visualizations
- Final integrated score visualization
- QED vs final score visualization
- Top 5 candidate comparison
