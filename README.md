# Agentic AI-Driven Drug Discovery and Lead Prioritization

An agentic computational drug-discovery pipeline for target validation, literature analysis, compound discovery, drug-likeness filtering, molecular docking, ADMET analysis, integrated candidate scoring, and lead prioritization.

> **Important:** This project generates computational predictions. The results should not be interpreted as experimental evidence of therapeutic efficacy. Experimental validation is required.

---

## Project Overview

This project demonstrates an end-to-end **Agentic AI-driven drug discovery workflow** using the **Epidermal Growth Factor Receptor (EGFR)** as the target.

The pipeline integrates multiple computational agents and analysis modules to move from target validation and literature research to compound screening, molecular docking, ADMET analysis, integrated candidate scoring, and final lead prioritization.

---

## Target

- **Target:** Epidermal Growth Factor Receptor (EGFR)
- **PDB structure:** 1M17
- **Receptor structure:** `1M17.pdb`
- **Prepared receptor:** `1M17.pdbqt`

---

## Objectives

The main objectives of this project are to:

1. Validate the selected drug target.
2. Retrieve and analyze relevant literature.
3. Discover candidate compounds.
4. Filter compounds using drug-likeness criteria.
5. Perform molecular docking against EGFR.
6. Analyze ADMET-related properties.
7. Integrate computational evidence into a candidate score.
8. Generate visualizations and lead-analysis reports.
9. Prioritize candidate compounds for further investigation.

# Computational Disclaimer

This project is intended for **research, educational, and computational drug-discovery purposes**.

The computational results generated by this pipeline should not be interpreted as experimental evidence of therapeutic efficacy.

Molecular docking scores, ADMET predictions, drug-likeness calculations, QED-related scores, and integrated candidate scores are computational predictions and are subject to the limitations of the underlying methods and assumptions.

The identified compounds should therefore be considered **computational candidates for further investigation**, rather than validated therapeutic candidates.

Experimental biochemical, cellular, pharmacological, toxicological, and clinical studies would be required to establish biological activity, efficacy, and safety.
